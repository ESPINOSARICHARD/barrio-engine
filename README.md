# Barrio Pizza — Centro Inteligente de Compras

Solución desarrollada para el reto técnico de la práctica profesional de Inteligencia Artificial de Barrio Pizza.

## Problema

Las sucursales preparan semanalmente sus órdenes de compra. La revisión manual puede provocar sobrepedidos, pedidos insuficientes, ingredientes omitidos y errores de datos.

## Objetivo

Construir una herramienta visual que:

- proyecte el consumo de la próxima semana;
- calcule la necesidad real de cada ingrediente;
- valide las órdenes antes de aprobarlas;
- genere alertas claras y accionables;
- recomiende cantidades en formatos completos de compra;
- permita obtener una orden corregida por proveedor.

## Principios de la solución

1. No inventar información que no exista en los datos.
2. Validar antes de analizar.
3. Mantener cada cálculo auditable.
4. Utilizar lógica determinista para las cantidades.
5. Utilizar IA para consultar y explicar resultados, no para inventarlos.
6. Diseñar la herramienta pensando en su evolución hacia una solución operativa.
